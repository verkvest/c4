Offline board

Aureline

Drop a disc down a column. The first player to line up four — across, down, or diagonal — takes the board. A full board with no line is a draw.

Credits and licenses

Aureline is an offline four-in-a-line game. Matches stay on this device. There is no account, no ads, and no online match server.
